# 学习资料工作台

面向国内大学生的单课程期末复习原型。围绕「资料上传 → 核对疑点 → 选择范围 → 带出处的复习提纲 → 个人编辑 → 增量更新」构建，支持持续保存与回看。

2026-09-29 更新：「知识点复习」现为每课程一本的「我的活页笔记」，支持章节目录、双页/手机单页、直接编辑、随处收录、离线草稿与独立版本快照。私人账号和 Linux 部署文件已实现；实际服务器尚未上线。最新能力与验证见 [活页笔记验收](docs/notebook-validation.md)，部署见 [私人学习空间部署](deploy/README.md)。下方带日期的说明保留各阶段的功能背景。

## 启动

使用 Node.js 22（本机验证版本 22.22.2）。首次运行：

```powershell
npm ci --legacy-peer-deps
Copy-Item .env.example .env
npm run db:setup
npm run ocr:setup
npm run dev
```

已有 `.env` 时保留原文件。主版本目录为 `C:\Users\13150\.claude\projects\LMS`，本地入口统一为 http://127.0.0.1:4175 。安装时自动准备 PDF 预览组件；样例 PDF 已包含在项目内，无需 Python。

`npm run dev` 和 `npm run dev:stable` 均使用 Webpack，开发缓存保存到独立的 `.next-app-shell`，不覆盖生产构建。

`ocr:setup` 首次联网下载中文识别语言文件，之后图片在本机运行 OCR，不发送课程资料到云端。跳过此步骤仍可提取 PDF 文字层，图片识别会提示安装语言文件。

## 真实文字提取（2026-09-15）

上传 PDF/PNG/JPG/DOCX/PPTX/TXT 后自动在本机提取文字，也可粘贴笔记加入上传队列。进入「我的资料」打开文件，在「识别文字」区域查看、导出 TXT 或重试。PDF 保留原页码，PPTX 保留幻灯片顺序，DOCX/TXT 使用段号（TXT 按换行计段），段号不等于打印页码。章节可自行命名。识别完成仅标记为「文字已提取 · 待整理」，不自动发送或生成内容。

PDF 优先提取文字层，没有文字层的页尝试本机 OCR，最多 50 页。Office/TXT 每次最多提取前 50 个段落或幻灯片，超出数量、文字预算或识别时间时明确提示不完整。DOCX/PPTX 不还原版式、图片、批注和复杂公式，请用原文件核对。旧版 DOC/PPT 请先另存为 DOCX/PPTX 或 PDF。OCR 适合清晰印刷体，数学符号、数字、英文和手写仍可能出错；中文扫描测试通过不代表内容准确率已经达标。

生产构建验证：`npm run build`。生产运行始终要求配置私人账号，按部署说明设置后启动；开发服务与生产服务使用同一个端口，只启动其中一个。

## 从真实资料生成复习材料（2026-09-11）

已接入 DeepSeek Responses API。本机已通过模型列表和简短结构化输出调用验证；整套课程资料的生成质量仍需人工验收。

在 `.env.local` 中填写 `DEEPSEEK_API_KEY` 并重启服务。`DEEPSEEK_MODEL` 默认 `deepseek-flash`，这是 DeepSeek-V4.1-Flash 的接口标识；模型展示名不能直接代替标识。`DEEPSEEK_REASONING_EFFORT` 默认 `high`，统一用于资料整理、出题和聊天。整卷资料整理的单次输出上限设为当前模型官方最大值 393216 的 50%，即 196608 token；实际用量以 API 返回为准。密钥只由服务端读取，不写入页面、数据库或生成记录；不要提交 `.env.local`。

1. 上传 PDF/PNG/JPG/DOCX/PPTX/TXT，等待文字提取完成。
2. 在「复习材料」点击「整理真实资料」或「从真实资料补充」，也可从首页进入。
3. 勾选原文位置，对照原文件修正文字、数字和公式。每次最多 20 个位置、40000 字；空白、未识别位置及已排除资料不纳入，不会静默截断生成请求。
4. 确认发送后，DeepSeek 仅收到所选页的核对后文字、资料标识和页码，不接收文件原件或未选页。调用可能产生 API 费用。
5. 先预览知识点、摘录引用和覆盖不足提示，再勾选采用。采用后保存新版本，原有段落、个人编辑与历史快照保留。

服务端校验引用的来源、页码及摘录是否存在于核对后文字中；这不等于结论已验证正确，所有新段落仍标为待核对。模型拒绝、截断、无效输出或错误引用不会保存为新版本。采用前若来源已排除、重新识别或课程已有新版本，旧预览会被拒绝。核对文字修订只用于本次生成，不覆盖原始识别记录。

接口依据：[DeepSeek Responses API](https://api-docs.deepseek.com/guides/responses_api/)。DeepSeek 文档说明 `store` 参数不受支持，不能将返回的 `store: false` 理解为云端完全不保留数据。原文提取仍在本机运行，只有用户主动生成才发送文字。

## 五分钟演示

V2 第一轮已加入学习首页和复习练习。首页根据当前课程状态显示「导入第一批资料」「整理这门课的重点」或「继续阅读复习材料」。左侧为学习首页、我的资料、复习材料、复习练习；历史版本入口在复习材料中。

完成材料生成后进入「复习练习」，可选择混合、选择、填空、简答。内置最多四道有出处的演示题。练习模式逐题反馈，自测（界面中的考试模式）整组交卷后查看解答，再逐题完成自评；这不是监考考试系统。简答提供段落、列表、加粗、公式工具及 Markdown 预览，尚不是完整所见即所得编辑器。首页显示当前题组进度；最近一次需巩固后 1 天、答对或自评覆盖要点后 3 天提醒，不代表掌握程度。

练习草稿和记录现保存在本机 SQLite，按课程、材料版本、题组及有效来源隔离。同一台服务上的浏览器可读取已保存进度，但多个页面的旧进度不会覆盖新记录。材料版本或可用引用范围改变后开启独立练习记录，旧记录保留。当前浏览器旧 localStorage 草稿若通过校验会自动迁移，原 localStorage 不删除；只有已保存到数据库的记录不受清理浏览器数据影响。等待「已保存到本机数据库」后再关闭页面。

## 真实资料练习与本机进度（2026-09-11）

在「复习练习」选择已核对的 DeepSeek 材料知识点，可生成最多五道选择、填空或简答题。出题请求只发送选中知识点正文与引用摘录；题目来源和摘录由服务端校验。新题先展示题干、参考答案及出处，用户确认核对后才启用。资料被排除或重新识别后，该题组暂停使用；旧记录不会删除。

选择题对照参考选项判定。填空按本题答案匹配文字、数值或等价分数，无法确定匹配时转为参考答案自评；简答按要点自评，没有 AI 语义评分。演示概率题保留已说明的小数误差规则，其余题目不再硬编码为 `2/3`。

DeepSeek 接口已完成简短连通性验证，真实资料出题效果仍需人工核对。已有演示练习、本机保存、续答和错题重练可直接使用。重练前会把上一轮完整答案存入 `PracticeRound`，可在「历史题组与作答」回看或导出；此前已被旧版本覆盖的答案无法补回。临时保存失败可保留答案并重试，旧页面仍不能覆盖新记录。更新现有安装前备份数据，再运行 `npm run db:setup` 同步结构。

答案提交并保存后，可主动同意把本题答案、题目、参考解答、要点与引用摘录发送给 DeepSeek 获取参考点评。点评包含已体现要点、可能遗漏、建议与不确定性，不自动评分或修改自评。出题和点评均校验知识点生成时的来源快照，重新识别后的旧知识点不能直接用于新题。点评当前只保留在页面中，离开或刷新后不恢复；真实模型质量仍未验收。

1. 打开「高中语文 · 学习之道」课程。资料库按章节归类，包含 2023、2024 年全国新课标语文整卷；同一套卷只保留一份。导入入口可重新添加已删除的真题资料。
2. 打开整卷后，先选现代文、古代诗文、语言文字运用、写作或答案，再按页展开已提取文字并对照原始 PDF。原卷跨页处可能包含相邻板块内容。
3. 整理复习材料时，先展开试卷，再按板块和页码选择需要核对的内容。
4. 点击「准备复习提纲」从已提取的真实资料整理内容；生成前需要配置 DeepSeek。核对引用后可在「复习练习」创建并审核题目。

旧「概率论与数理统计」课程与「概率论 · 完整演示」仍在课程书架中，已有资料、提纲和作答记录不会迁移或删除。可通过课程旁的加号添加空课程，从上传开始体验。

资料来源：[2023 年新课标Ⅰ卷网络整理版](https://static.ltdcdn.com/uploadfilev2/file/0/534/647/2024-03/17108961629859.pdf)、[2024 年新课标Ⅰ卷及参考答案](https://static-gkcx.gaokao.cn/upload/zhenti/20240612/1718157275_1581.pdf)、[2024 年新课标Ⅱ卷](https://down.jiaoyuwu.com/m00/1a/d5/7717046b7687dad50fb7f70cbff68f9c.pdf)。2023 年整理版的「现代文阅读」总分标题误排为 36 分，题目分值合计为 35 分；对照原题时请以题目分值为准。2023 年整理版与 2024 年Ⅱ卷文件不含答案，资料详情页会明确提示。

## 真实能力与演示边界

- 文件上传、内容去重、课程隔离、PDF/图片预览、章节调整、范围排除、编辑保存、版本记录和 Markdown 导出均实际运行。
- 内置样例的分类、冲突识别、提纲和练习仍为预设演示逻辑。普通资料可提取文字，并在启用 DeepSeek 后主动生成候选材料、练习和参考点评，不会套用演示答案；真实模型效果尚未实测。
- 四份资料均为 AI 辅助自编的简短中文 PDF；冲突笔记故意包含错误并有明显标识。它们不是高校课件、真实学生笔记或历年真题。
- 当前提供本机使用和私人账号部署代码，已接入可配置的 DeepSeek 生成接口；尚未部署到真实服务器。登录与完整备份恢复已验证，录音转写、聊天记录导入、共享权限和多人协作仍属于后续设计范围。
- 当前上传支持 PDF/PNG/JPG/DOCX/PPTX/TXT，每份不超过 100 MB。文件先进入本机导入收件箱，确认课程后才加入资料库并提取文字。这是原型范围，与题目平台的最终附件提交限制不同。

## 数据与验证

数据保存在 `data/workbench.db`、`data/uploads/`、`data/extractions/` 和 `data/generations/`。生成记录保留原识别文字、核对后文字、来源摘要、候选内容、模型和时间；关闭窗口后可在整理窗口的「待采用的生成预览」恢复有效候选，不会再次调用模型。资料或版本变化后的预览不可恢复或采用。停止服务后一起备份数据库、原文件、识别结果与生成记录。`data/ocr-models/` 可重新下载。复习材料版本为不可变快照；原文件和 OCR 的完整历史版本未单独保存，历史题组保留当时的引用摘录及来源摘要。

`npm run check` 检查类型，`npm test` 本轮执行 261 项逻辑、接口与组件测试。接口测试使用独立 SQLite 和模拟模型响应，不修改课程数据。最新浏览器验证及模拟边界见 [活页笔记验收](docs/notebook-validation.md)。

`npm run test:extraction` 执行 9 项真实提取与超时测试，需先安装本机 OCR 语言文件。生产运行使用完整项目目录和 `node_modules`（`npm start`）；独立识别脚本不适用于直接复制精简 standalone 目录或受限的 serverless 环境。

2026-09-29 执行 `npm audit --omit=dev`，本次未报告生产依赖已知漏洞；后续部署时应重新检查。
