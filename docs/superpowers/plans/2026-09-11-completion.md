# 复习工作台后续开发计划

目标：按用户授权继续补齐已设计的单人学习流程，自行测试后集中提供真实体验验收步骤。

架构：沿用 Next.js、本机 SQLite、原文件与识别快照、OpenAI 结构化接口。保留现有课程及历史，不创建另一套演示产品。API 密钥配置继续暂缓。

技术：现有 React、Prisma、PDF.js、Tesseract.js；Office 文档采用有资源限制的本机结构化解析。

- [x] 导入：DOCX/PPTX/TXT、粘贴文字；验证真实格式、错误文件、段落/幻灯片定位、去重、扫描 PDF OCR。
- [x] 通用课程：自定义章节、非 PDF 文档文字阅读、明确原文定位单位；检查手机布局。
- [x] 恢复：已生成预览重新打开；验证课程隔离、过期来源与版本拒绝。
- [x] 作答：编辑工具、学习首页续答、待复习提示、考试模式、历史轮次；验证草稿和自评分数不受影响。
- [x] AI 点评：主动发送已保存答案、服务端读取题目与出处、结构化参考意见；拒绝过期来源，保留自评。
- [x] 总体验：类型、逻辑、接口、真实提取、生产构建、浏览器实测；记录不能由模拟测试证明的结果。详情见 prototype-validation.md 的 2026-09-15 记录。
- [x] 更新 README 和统一验收清单；未完成项逐一说明，不把本机单人版称为全部产品完成。

独立系统边界：正式登录、共享权限和云端同步需要从本机单人架构进入服务端部署及身份体系；外部 QQ/网盘授权、转写、手写理解与代码隔离执行也是独立接入。当前没有这些服务的选型、凭证或部署目标，保留为待实现，不伪造连接状态。真实模型评测必须在配置有效密钥后执行。用户体验验收留到已承诺功能的工程验证之后。
