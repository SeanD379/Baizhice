## 1. 用户反馈与定位

当前首页没有说明学生应该先做什么，资料管理操作占据主位置。学生真正想完成的是：将相册拍照、网盘课件和 QQ 文件集中导入，让系统完成内容识别、归类与整理，得到可用于复习的材料，并通过练习巩固。

新定位：面向国内大学生的课程复习工作台。接收零散课程资料，自动组织成有出处的复习内容，再用练习帮助学生发现和弥补薄弱点。长期支持多课程，首次体验从一门课开始。

## 2. 参考产品与可借鉴部分

- [Quizlet Study Guides](https://quizlet.com/features/study-guides/)：从笔记、PDF、幻灯片生成可编辑学习资料，再转入卡片和测验。借鉴导入后直接交付可学习内容。
- [RemNote Guided Learn](https://help.remnote.com/en/articles/15724936-guided-learn-mode)：按资料小节组织摘要、卡片与测验，支持练习和测试两种模式。借鉴连续学习路径以及错题与知识点的关联。
- [RemNote Typed Answers](https://help.remnote.com/en/articles/7752298-typing-in-answers)：支持精确、模糊与 AI 语义判定。借鉴不同答案类型采用不同判定规则。
- [Google 官方移动端说明](https://support.google.com/gemininotebook/answer/16296687)：支持从移动端分享内容进入笔记空间，以及基于来源生成学习卡片和测验。借鉴资料收集入口靠近原使用场景；不据此推断国内 QQ 或网盘接口可用。

这些是功能模式参考，官方介绍不能证明本产品对国内大学生的学习效果。

## 3. 首次与回访流程

首次首页主标题：把零散资料，变成这门课的复习材料。

正文：上传课件、课堂照片和老师的复习文档，系统帮你整理重点，再用练习查漏补缺。

主操作「导入第一批资料」，次操作「用中文样例体验」。只展示三步：导入资料 → 自动整理 → 开始复习。每步由实际任务状态推进，可跳过介绍并随时重新查看。

上传时可选课程；不确定课程的文件先进入待归属区。无需先建目录、填标签或逐份分类。考试日期、考试范围、熟悉程度为可选项，后续可补充。

处理过程中显示实际进度及失败文件；成功部分先可用。完成后展示识别了什么、覆盖哪些章节、有哪些疑点，并直接提供「阅读复习材料」和「先练 5 题」两个入口。5 题是起始建议，无足够依据时应减少题量并说明。

回访首页优先显示继续阅读、未完成练习、待复习错题与新资料处理结果；不重复显示新手教程。

## 4. 导入与自动整理

| 输入 | 拟定处理 |
| --- | --- |
| 数字 PDF、PPT/PPTX、Word | 优先提取文字和结构，保留页码、幻灯片及段落定位 |
| 相册照片、扫描 PDF | 图片纠偏、OCR、版面与公式识别，标记无法可靠识别的片段 |
| 复制的文字 | 保存内容及用户提供的来源说明 |
| QQ、网盘资料 | 第一阶段支持用户下载后批量拖入；直接授权导入、移动分享、网盘同步分别验证后接入 |

长期需要解决收集成本：手机拍照或分享即进入统一收件箱，系统自动建议课程；只对不确定的归属向学生提问。普通网页不能在后台随意读取手机相册、QQ 和网盘，当前原型不应显示未实现的连接成功状态。

自动流程：保存原件和来源 → 解析/OCR → 去重及版本识别 → 归入课程与章节 → 提取知识点 → 关联原文依据 → 生成复习材料。

同名不等于同一文件，同一主题也不等于重复。来自课件和笔记的互补说明应保留出处。局部冲突或低质量识别先隔离对应片段，让其他内容继续整理；学生只确认可能影响结论的问题。

复习材料包含：章节概览、知识点及适用条件、关键公式、典型例题、易混点、未覆盖内容。教师明确给出的考试范围与 AI 推测重点分别标记。

## 5. 导航与复习流程

侧栏：学习首页 / 我的资料 / 复习材料 / 复习练习。课程切换保留；版本记录移入对应材料的历史入口。错题和学习记录先放在复习练习内部，避免增加过多一级导航。

默认连续路径：阅读一个知识点 → 做几题 → 查看反馈 → 回看原文 → 再次练习。熟悉的学生可以直接开始练习。

练习模式逐题反馈，提供分级提示及重答；自测模式提交整组后再给答案，区分看过提示与独立作答。错题复习优先覆盖曾出错和较久未复习的知识点，不无限重复原题。初期显示最近练习表现及题量，不将一次答对显示为掌握百分比。

## 6. 出题与点评

知识单元包括概念、前提条件、公式、例子、易错点及原始引用。出题不按固定字数机械切段，也不为每段强行出题。每题保存关联知识点、题型、参考答案、评分要点、出处和来源版本。

资料原题与 AI 自编练习分开标记。没有可信解答、来源冲突或识别失败的内容不进入自动判分题池。AI 补充推导标记为参考解答并核验；教师答案与 AI 参考解答发生冲突时暂停判分。

| 题型 | 作答与反馈设计 |
| --- | --- |
| 选择题 | 点选作答；核验唯一或明确的多选答案，解释错误选项对应的误区 |
| 填空题 | 文本或公式输入；处理同义词、数学等价、单位及合理数值误差 |
| 简答题 | 轻量富文本；按要点覆盖、事实错误、遗漏条件逐项反馈，接受合理不同表述 |
| 计算题 | 分步作答、公式编辑、手写照片；分开检查思路、步骤、单位和结果，避免只看最后答案 |
| 编程题 | 代码编辑器与思路区；真实执行必须有隔离运行环境和测试用例，未执行时仅提供代码阅读建议 |

点评顺序：完成了哪些要点 → 哪一步有问题及依据 → 如何改进 → 返回相关资料或尝试变式题。识别不清或依据不足时允许「暂无法可靠判断」，提供查看评分要点、自评和报告问题入口。

主观题采用类似 Word 的段落、列表、公式、插图和自动保存；编程题使用适合代码缩进、高亮与语言选择的专用输入区。计算题允许纸上作答后上传照片，先校对识别出的表达式再点评。

## 7. 数据关系与持续使用

原始资料版本 → 原文片段 → 知识点 → 复习材料 / 题目 → 作答记录 → 后续复习任务。

题目和点评需要保存使用的资料版本、参考解答及评分标准。原文被修改或排除后标记受影响的题目待复核，暂停其自动判分；历史作答保持原记录，避免分数随资料更新静默变化。

## 8. 实施顺序与验收建议

第一步：改首页及导航，做连续导入引导、可读的处理结果和明确的下一步入口。

第二步：打通真实中文文字 PDF、图片 OCR、PPT/Word 的最小整理链路，保存引用定位；至少用一组混合资料验证，不能一直以哈希样例代替内容处理。

第三步：实现知识点关联的选择、填空、简答练习，作答记录、点评和错题复习。先保证题目与判断有依据，再增加题量或复杂的掌握度算法。

第四步：完善公式、手写、编程题执行、多端收集、授权导入与分享权限。

拟定初轮可用性验收：邀请 5–8 名国内大学生，不口头讲解首页，观察能否在 30 秒内说出产品用途并找到导入入口。记录从收集到得到可用复习材料的总耗时，包括等待、检查与纠错；与原方法比较，不能只统计生成速度。

题目评测由人工核验：是否超出资料、题干是否完整、答案是否成立、引用是否支持、同义或不同解法是否被误判。故意放入错误笔记、低质量照片、缺失答案和不同版本，验证系统会提示或暂停。以上为拟定验收方法，尚无实测结论。
