# 活页笔记与私人学习空间验收

更新：2026-09-29。本地功能和可部署代码已完成；现有 Linux 服务器的连接、域名、HTTPS 和真实手机移动网络验收尚待确认。本记录不表示已上线。

## 已完成的体验

- 每课程一本当前笔记，章节与知识点目录、名称调整、排序、移动、全文搜索和命中片段定位。上次位置按知识点与续页锚点恢复，页码由正文排版计算。
- 1092×871 下双页阅读，390px 下单页；目录抽屉、宽屏固定目录和字号设置。长段落、编号列表和引用可续页，正文不截断。
- 点击正文进入连续编辑，完成后回到对应阅读页。Tiptap 支持标题、列表、加粗、引用、图片、公式、段落移动、撤销与重做。移除活页进入回收区，恢复保留知识点 ID、正文与来源。
- 资料文字、PDF 选文、AI 回答、练习反馈和错题复盘可收录到已有知识点、新活页或待整理。收录后留在当前学习位置；目标被另一设备删除时提示重新选择，内容保留。
- AI 草稿逐段确认，选择追加位置与章节；相似标题提示追加。各批次来源独立，个人补充不会被覆盖，重复采用不会重复追加。
- 停止输入约一秒后保存；完成编辑、采用草稿和目录整理建立独立笔记快照，内容相同时不重复建立。旧提纲、题目与作答快照保留；旧套卷摘要留在历史中。
- 修订号防止旧稿覆盖，请求 ID 使重试幂等。未同步文字与图片保留在 IndexedDB，回网后上传并保存。双设备冲突可对照并保留两稿，或将本机稿移入回收区；浏览器无法落盘时明确要求保持页面打开。
- Better Auth 固定私人账号，关闭公开注册。生产环境始终要求登录，页面、全部学习 API、资料原件和笔记图片均受保护；开发环境可继续本机使用。
