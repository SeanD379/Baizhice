# 中文资料识别方案与首轮验证

日期：2026-09-10。本轮目标是读取真实文件内容并保留原页码，尚不生成用户资料的复习材料。

## 方案比较

| 方案 | 适合的任务 | 接入与费用 | 当前结论 |
| --- | --- | --- | --- |
| PDF.js 文字层提取 | 数字 PDF 中已存在的文字 | 本机运行，无按次接口费 | 已接入；避免对清晰文字再次 OCR |
| Tesseract.js 中文 OCR | 清晰印刷体图片的初步识别 | 本机 CPU；首次下载语言文件，识别时不发送资料到云端 | 已接入作为可运行基线；测试出现数学符号和数字识别错误 |
| PaddleOCR / PP-StructureV3 | 版面、表格、公式等文档解析 | 自部署需额外 Python/推理环境与资源，无本项目实测 | 下一轮复杂文档候选，不能先宣称达到课件质量要求 |
| 阿里云 Qwen OCR | 云端图像文字识别 | 需要百炼凭据，按输入和输出 Token 计费，资料会发送至选定服务 | 云端候选，尚未调用或实测，未产生接口费用 |

技术依据：[Tesseract.js API](https://github.com/naptha/tesseract.js/blob/master/docs/api.md)、[本地安装说明](https://github.com/naptha/tesseract.js/blob/master/docs/local-installation.md)、[PaddleOCR 官方文档](https://github.com/PaddlePaddle/PaddleOCR/blob/main/docs/version3.x/pipeline_usage/PP-StructureV3.md)、[Qwen OCR 模型信息](https://help.aliyun.com/zh/model-studio/qwenvl-ocr)。

费用参考：查询时百炼华北2（北京）`qwen-vl-ocr` 输入为 0.3 元/百万 Token、输出为 0.5 元/百万 Token；实际费用取决于图片输入 Token、输出长度、地域和模型版本，不能把它当成每页固定价格。开通前按[官方价格表](https://help.aliyun.com/zh/model-studio/model-pricing)再次核验。该价格不含后续整理和出题所用模型，也不保证 OCR 质量。

当前建议：先用本机方案打通保存、识别、逐页核对；复杂课件与手写再使用同一组测试资料比较 PaddleOCR 与云端服务。没有用户提供的真实课堂资料和云端实测，暂不评定哪个方案最终胜出。

## 本轮实现

1. 普通 PDF/PNG/JPG 从网页上传后自动触发本机提取。文件先保存，识别失败不丢失文件。
2. PDF 保留每页文字与页号，最多 50 页；图片使用本机简体中文 OCR。扫描 PDF 未自动转图 OCR，没有文字层的页会显式列为待处理。
3. 资料详情显示识别结果、处理时间、页码及核对提示，可跳到对应原文页并全屏阅读。
4. 识别结果可导出 TXT、重新提取、刷新后重新读取。普通文件提取成功后标记为「文字已提取 · 待整理」，不会进入样例提纲或练习。
5. 识别在独立 Node 进程执行，单任务超时 110 秒，同时最多两项，同一文件重复请求复用正在执行的任务。识别数据保存在本机 `data/extractions/`。

## 实测证据与限制

- 中文 PDF：读取实际文字层，提取出「条件概率」、交集符号以及 `8/12 = 2/3`。
- 图片 OCR：同一页的清晰 PNG 在本机约 2 秒返回中文内容，但将交集符号误读，并漏掉例题分数中的数字。识别器信心值不能作为内容正确率。
- 多页文件：第二页文字可以定位到 PDF 第二页，包括全屏查看；没有文字的第三页仍在结果列表，不能被当作识别成功。
- 异常文件：超过 50 页以及结构损坏的 PDF 被拒绝；原文件保留。
- 以上素材来自项目自编中文演示资料及测试页，并非真实大学课堂资料。样例识别实际运行了算法，不再依赖文件名或样例哈希返回预设文字。
- 未验证真实手写、拍照畸变、多栏阅读顺序、复杂公式、表格重建和低清图片的可用率。文本提取完成不等于内容通过学术核验。

验证命令：`npm run check`、`npm test`（9 项逻辑用例）、`npm run test:extraction`（4 项真实提取测试）、`npm run build`。浏览器另验证上传后自动提取、持久化、重试、TXT 下载、原页跳转及窄屏显示。

## 接下来

使用真实中文课程资料人工标注 OCR 错误，分别统计正文、公式、数字的错误率及纠正时间，再决定是否更换识别引擎。核验识别链路后接入知识点整理与引用生成；OCR 原文应保留，不让后续生成覆盖原始识别结果。
