# AI 学习资料工作台｜页面结构与技术方案 V1

日期：2026-09-09。面向国内大学生的单门课程期末复习；核心价值为可追溯的复习材料。

## 1. 本次交付与边界

本次提供页面信息架构、可点击低保真线框、关键状态和正式原型技术选型。线框用于检查布局及操作路径，不代表文件解析、模型生成、持久化或正式界面已完成。

预览入口：`wireframe.html`。可直接在浏览器打开，也可以在项目目录执行 `node docs/preview.mjs`，访问终端显示的本地地址。预览服务仅监听本机，不提供正式文件上传接口。

正式原型按 Node.js 网页应用实现：浏览器承担界面和交互，Node.js 承担上传、数据保存及处理请求。首版聚焦桌面工作台，兼顾窄屏阅读。课程资料和产品文案全部使用中文。

## 2. 信息架构

工作台保留稳定的课程上下文，不把每一步设计成独立全屏向导。

| 区域 | 承载内容 | 设计决定 |
| --- | --- | --- |
| 左侧导航 | 当前课程、资料库、复习材料、版本记录 | 切换模块时保留课程及未保存编辑 |
| 顶部上下文 | 当前课程、当前位置、本模块主要操作 | 资料库主操作为上传；提纲主操作为保存 |
| 中间主区 | 资料列表、复习提纲或版本对比 | 根据当前任务切换，正文为阅读视觉重心 |
| 右侧面板 | 资料详情、来源、疑点、原文对照 | 按需打开，不永久占据阅读空间 |
| 模态窗口 | 批量上传、生成范围确认 | 用于短任务；取消后返回原位置 |
| 状态提示 | 处理中、保存结果、失败及重试 | 关键问题留在页面，短暂提示只用于已完成动作 |

首版只展示有作用的课程信息和任务状态，不添加活跃度、学习时长等无数据依据的统计卡片。

## 3. 关键页面与低保真布局

### A. 课程资料库

```text
┌─────────────┬───────────────────────────────────────────┐
│ 学习资料     │ 概率论与数理统计  /  资料库        上传资料 │
│             ├───────────────────────────┬───────────────┤
│ 当前课程     │ 资料搜索与类型筛选         │ 按需展开面板   │
│ 概率论       │                           │               │
│             │ 待确认事项：问题和影响      │ 资料信息       │
│ 资料库       │                           │ 原始出处       │
│ 复习材料     │ 文件名 / 章节 / 状态       │ 导入渠道       │
│ 版本记录     │ 文件名 / 章节 / 状态       │ 识别问题       │
│             │ 文件名 / 章节 / 状态       │ 处理操作       │
│             │                           │               │
│             │ 复习准备入口：选择范围 →   │               │
└─────────────┴───────────────────────────┴───────────────┘
```

每条资料显示类型、名称、章节及处理状态。导入时间与原创时间分开；不知道作者或年份时显示未知。可以搜索名称、筛选状态，并在详情中修改归属。完整重复文件复用内容，保留导入记录；内容相近不能直接删除。

疑点面板并列展示问题内容、参照原文及影响。操作为“本次排除”“采用指定来源”“保留差异”，不用含义模糊的单一“确认”。排除只改变本次生成范围。

### B. 复习材料

```text
┌─────────────┬───────────────────────────────────────────┐
│ 课程导航     │ 概率论  /  复习材料             保存修改   │
│             ├───────────────────────────┬───────────────┤
│             │ 提纲名称 / 版本 / 状态     │ 原文对照       │
│ 资料库       │ 使用资料与已排除内容       │               │
│ 复习材料     │                           │ 文件名称       │
│ 版本记录     │ 01 条件概率               │ 页码 / 放大    │
│             │ 概念、条件、公式 [出处]    │ 原文页与定位   │
│             │                           │               │
│             │ 02 独立性                 │ 引用说明       │
│             │ 定义与易错点 [出处]        │ 纠正识别结果   │
│             │                           │               │
│             │ 关联例题与已知缺口         │               │
└─────────────┴───────────────────────────┴───────────────┘
```

右侧默认收起；点击出处时展开并定位对应文件位置。正式原型使用实际原文文件或明确标注的自编样例，不能用重新生成的文字冒充原文截图。

正文使用结构化知识点，每条保留出处、用户编辑状态。首版采用逐段编辑；支持数学公式显示，不先做复杂富文本工具栏。未保存编辑在切换页面或关闭前提示处理。多个章节可通过正文目录跳转。

### C. 版本记录与更新对比

```text
┌─────────────┬───────────────────────────────────────────┐
│ 课程导航     │ 复习材料  /  更新对比        保存为新版本  │
│             ├───────────────────────────────────────────┤
│             │ 新增资料 / 影响知识点 / 待处理冲突         │
│             ├─────────────────────┬─────────────────────┤
│             │ 当前版本             │ 建议更新             │
│             │ 现有正文             │ 新增内容             │
│             │ 用户编辑标识         │ 修改原因与出处       │
│             ├─────────────────────┴─────────────────────┤
│             │ 逐项采用 / 保留现有内容 / 查看历史版本     │
└─────────────┴───────────────────────────────────────────┘
```

没有新增资料时展示历史版本列表，不显示空白对比。更新提纲必须产生新版本；用户编辑过的段落默认保留。版本页面显示“待审阅更新”和“已保存历史”两种明确状态。

## 4. 上传与范围确认

上传窗口包含文件选择、批量列表、逐文件状态和继续上传入口。正式原型第一批支持 PDF、PNG、JPG；PPT/PPTX、音频及聊天文件导入放到真实处理阶段接入。课件可以先使用 PDF 导出版，界面应直接说明支持范围。

上传成功后留在资料工作台，可以关闭窗口，处理任务不因此取消。失败项可以单独重试，成功项继续。文件大小上限在实现时按服务能力设定，不能沿用作业附件的 300MB 限制。

生成范围窗口展示：目标章节、纳入资料、已排除内容、仍存在的缺口。关键疑点需处理或排除受影响内容，之后才可生成。没有可用内容时给出补充资料入口。

## 5. 必须覆盖的界面状态

| 对象 | 关键状态 | 用户能做什么 |
| --- | --- | --- |
| 课程 | 首次空白、已有资料 | 上传资料或查看成果；演示资料入口明确标记 |
| 文件 | 待上传、上传中、解析中、可用、部分可用、失败 | 查看进度、查看问题、补充或重试 |
| 疑点 | 待处理、已采用依据、已排除、保留争议 | 查看出处并更改本次选择 |
| 生成 | 范围待确认、处理中、部分完成、失败、草稿完成 | 查看任务、重试、核对草稿 |
| 编辑 | 已保存、有未保存修改、保存失败 | 保存、保留编辑重试或明确放弃 |
| 更新 | 无更新、有候选更新、对比中、已保存新版本 | 查看变化、逐项采用、查阅旧版本 |
| 原文 | 加载中、已定位、定位失败、无访问权限 | 重试、打开源文件或返回提纲 |

状态变化同时使用文字及视觉标记，不只依靠颜色。模态窗口支持键盘操作、关闭和焦点返回。小屏上导航可折叠，右侧面板改为单独阅读层，不挤压正文或出现整页横向滚动。

## 6. 正式可交互原型技术栈

| 层次 | 选型 | 作用与范围 |
| --- | --- | --- |
| 运行环境 | Node.js；沿用已检查的本机 22.22.2，安装时核对依赖支持范围 | 启动开发服务和服务端请求处理；项目记录 Node 版本 |
| 应用框架 | Next.js App Router + React + TypeScript | 同一项目组织工作台界面、路由和服务端处理，减少前后端分开维护 |
| 样式与组件 | Tailwind CSS + shadcn/ui + Lucide 图标 | 统一表格、按钮、面板、对话框和状态样式；使用系统中文字体 |
| 表单与校验 | 原生表单 + Zod | 检查文件元数据、范围选择和保存请求；服务端再次校验 |
| 页面状态 | React useState / useReducer | 管理当前选择、面板和编辑草稿；首版无需再增加全局状态库 |
| 持久化 | SQLite + Prisma | 保存课程、资料元数据、处理状态、引用、提纲及历史版本 |
| 原始文件 | 本地专用数据目录 + 数据库记录 | 本机单人原型保存文件；运行数据不提交到代码仓库、不放入公开静态目录 |
| 文件查看 | PDF.js + 浏览器图片预览 | PDF 翻页、原文位置定位、图片查看；PDF.js 不是 OCR 引擎 |
| 提纲内容 | 结构化知识点 + Markdown 展示 + KaTeX 数学公式 | 正文与引用分开存储，公式和中文说明清晰展示；不执行上传内容中的 HTML |
| AI 演示 | Node.js 端预置中文素材及确定性模拟处理 | 演示上传后整理、疑点、生成和更新；样例选择必须影响结果 |
| 自动检查 | Vitest + Playwright | 验证排除资料不再被引用、编辑保留、完整流程、键盘与窄屏行为 |
| 包管理 | npm + 锁文件 | 固定实际安装版本，便于在同一环境复现 |

SQLite 和本地文件仅对应本机单人持久化原型。后续多人在线使用时再评估 PostgreSQL 与对象存储，并补齐登录及服务端授权。不能将 SQLite 文件直接放在临时运行环境里就宣称数据持久可靠。

不提前增加向量数据库、微服务或复杂任务平台。只有真实资料规模、处理耗时和检索质量提出需要时再引入。

### 实际能力与模拟能力

正式原型计划真实实现：文件选择与本机保存、资料状态、范围选择、疑点操作、参考内容定位、提纲编辑、版本保存和页面返回。

首版模拟：OCR、语音转写、自动知识点理解、内容冲突识别和生成。界面始终明确“演示模式”。自带样例可走预设完整流程；任意新文件不得套用概率论预设结果，应该明确显示尚未接入真实解析/生成。

原型不调用收费模型、不外发文件、不声称实现真实多人权限。共享只做设计说明，正式提供多人入口时必须实现服务端鉴权。

## 7. 后续真实处理阶段的增量技术

1. 通用大模型：通过服务端接入支持中文的供应商接口。供应商待实际质量、成本和服务条件评测后决定，密钥只在服务端。
2. OCR 与语音转写：分别接入相应服务，保留识别内容到原图位置/录音时间的对应关系，并用公式、手写体、噪声音频单独评测。
3. 长任务处理：从数据库任务记录和独立 Node.js 工作进程起步；按并发需求再决定是否使用队列。
4. 检索与引用：按课程和已选范围筛选内容片段，附来源标识；扩大资料规模后再评估全文检索或向量检索。
5. 在线协作：登录、课程成员、文件及衍生提纲权限、版本冲突处理、删除与撤销共享联动。

## 8. 关键数据关系

课程 → 多份资料 → 多个带原文位置的内容片段。

生成任务记录所选资料版本、排除项和复习范围 → 产生提纲版本。

提纲版本 → 多条知识点 → 对应原文片段引用。

用户编辑标记与原有引用关系一起保存；若编辑改变了事实含义，引用需要重新核对，不能自动延续“有依据”的状态。

## 10. 原型开发顺序与验收

1. 工作台外壳及空状态：检查课程上下文、路由返回、桌面和窄屏布局。
2. 上传和资料库：检查本机保存、重试、文件状态与真实内容预览。
3. 模拟整理和疑点：检查选择对生成范围的实际影响。
4. 提纲生成、引用和编辑：检查出处定位、保存失败恢复和编辑保留。
5. 更新与版本：检查逐项采用、旧版本保留和新增资料后的完整演示。
6. 按评测方案执行用户任务测试；真实模型质量及速度另行评测。
